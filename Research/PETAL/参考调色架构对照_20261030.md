# 参考调色架构对照：编码器、交互与监督

核查日期：2026-10-30。仅使用原论文、作者项目页与官方仓库；没有运行第三方复现、没有访问 Trinity、没有修改 Model 代码。下文把论文事实、官方实现与我们的推断分别说明。

## 先给结论

文献不支持“一个不带位置编码的小网络自然就能提取纯风格”，也不支持“预训练视觉编码器必然不适合调色”。已有路线至少有三类：任务训练的小 CNN（Neural Preset）、预训练视觉骨干加任务适配（RefRetouch、PREEN）、显式颜色统计加可学习映射（StatLUT）。应在同一渲染器、数据和预算下对照，避免先由架构名称决定结论。

当前最值得借鉴的是：共享单图编码器保证两图可比较；保留未经归一化抹掉的颜色/亮度证据；分开“单图可缓存描述”与“内容—参考关系推断”；单独限制局部渲染自由度。以上分别已有先例，不能合起来就宣称新颖。

## 1. 索引与证据状态

| 方法 | 编码/预训练证据 | 共享关系 | 条件交互与渲染 | 核查层级 |
|---|---|---|---|---|
| Deep Preset / WACV 2021 | 自定义双分支 CNN；没有看到加载 ImageNet 骨干的路径 | T 与 C 独立；不是两张图各过一个 Siamese encoder | T 直接处理拼接的输入/参考；多尺度与 C 拼接，U-Net 解码；另预测 69 参数 | 论文＋官方源码 |
| Neural Preset / CVPR 2023 | EfficientNet-B0、256²；初始化是否 ImageNet 预训练待核实 | 论文明确共享 E；d/r 两种输出，n/s 映射参数独立 | 输入颜色归一化，再按参考参数重新着色；逐像素 DNCM | 论文；官方仓库主要开放 metric，核心模型未核实 |
| SA-LUT / ICCV 2025 | normalized VGG 预训练；另有浅层 CNN | 官方代码：VGG 共享；context 的 content/style CNN 不共享 | VGG 多尺度 AdaIN；另一路 content-query/style-key-value；4D LUT | 论文＋官方源码，部分实现比论文描述多 |
| StatLUT / 2026 预印本 | 参考图分支用固定 Lab 统计，不需预训练视觉骨干 | 固定提取规则相同；mapper 有角色特定分支，不应称“双塔全共享” | 内容统计、差值、全局统计构成 memory；identity LUT 作 query | 原论文方法＋补充；官方核心代码未找到 |
| RefRetouch / ECCV 2026 | 预训练 SigLIPv2 so400m，LoRA 适配 | 原图/修图的 Siamese 主干共享 | 两图 pooled feature 拼接成 edit latent；conditional pixel MLP | 官方 PDF 正文＋补充；仓库目前只有 README |
| PREEN / 2026 预印本 | CLIP ViT-L/14；先冻结，后 LoRA | 论文明确输入/参考共享视觉编码器 | 两个 768 维 embedding＋123 维统计；双 MLP 输出 29 编辑参数 | 原论文正文＋补充；未核实官方源码 |
| NLUT / 2023 预印本 | normalized VGG 预训练且冻结 | 输入/参考共用同一 encoder | 四尺度 AdaIN/splatting；压缩基 LUT 混合；含测试时调优 | 原论文＋官方源码 |

“可训练参数少”不等于“推理模型小”：LoRA 方法仍需要保存和执行基础视觉骨干。不能把 LoRA 更新量与我们完整模型参数直接比较。

## 2. 逐项核查

### 2.1 Deep Preset：学习变换的条件分支，而非纯参考塔

论文的 T 接收内容 X 和参考 Z，C 仅处理 X；T/C 多尺度特征交给解码器，T 的末端还预测预设并形成 1024 维嵌入。训练含输出 MSE、LPIPS、预设 L1 和同预设跨图的正对一致性。由此可见，“不同内容下表征一致”早已有显式监督，而非仅靠网络结构。[原论文 §2.2–2.3](https://arxiv.org/html/2007.10701v2)

官方 `stylize` 先将 X/R1 在通道维拼接，再分别执行 `tconv_i` 与 `cconv_i`；两套层是不同对象。T 中间特征未经纯统计池化就参与空间解码，不能把 T 叫作内容无关参考编码器。源码构建自定义卷积层；“未见外部预训练加载”不等同于证明所有历史训练配置都从零开始。[network.py L29–35、L72–99](https://github.com/minhmanho/deep_preset/blob/04eb47352e2f4cd643d466c7c6835f17d9513c92/networks/network.py#L29)

可吸收：为编码器提供能反映调色变换的监督。不要复制：为了辅助预设回归而采用大 flatten 全连接头；我们没有 69 参数真值，也不应假造此监督。

### 2.2 Neural Preset：共享轻量 CNN，显式分离归一化与重着色

同一个 E 从每张图输出 d/r；输入用自己的 d 进入归一化域，再用参考的 r 重着色。nDNCM/sDNCM 的投影不同。E 是 EfficientNet-B0、输入 256²。用同图不同颜色扰动训练：归一化结果 L2 一致，交换风格后 L1 重建。论文明确共享，但未找到初始化预训练状态的明确说明，应保留“待核实”。[原论文 §3.2–4](https://arxiv.org/html/2303.13511v1)

官方仓库在核查 commit 中的 Python 文件主要是风格/结构度量，不能用非官方重实现推断作者的初始化。[官方仓库](https://github.com/ZHKKKe/NeuralPreset/tree/6ccb50374ba2fcfa80137823159951c147ed50db)

可吸收：低分辨率共享编码和可缓存单图参数。不要复制：把“中性域”当作物理真值；不能假设这种分解唯一。另，公开 DNCM 公式是矩阵连乘，按字面固定图像可折叠为全局线性颜色映射；没有额外非线性的证据时，不应称其等价任意非线性 LUT。

### 2.3 SA-LUT：同一个系统同时存在共享与不共享

论文以预训练 VGG 多尺度参考特征预测 4D LUT 基的系数；上下文生成器引入内容—参考 cross-attention。训练结合同 LUT 合成配对、真实照片流、LPIPS、LUT 约束与对抗风格对应。它已经直接研究空间适应性，不能把“参考条件＋局部 LUT”单独当作我们的贡献。[原论文 §3](https://arxiv.org/html/2506.13465v1)

官方实现更具体：`VLog2StyleNet4D` 加载 normalized VGG，并对内容与参考调用同一 `self.encoder`，四尺度 AdaIN 后池化拼接生成权重；不同于正文简图的纯参考路径。上下文分支则各自实例化 content/style CNN（Conv、InstanceNorm、ResidualBlock），内容产生 Q，参考产生 K/V；这里不共享。[model.py L383–488](https://github.com/Ry3nG/SA-LUT/blob/3e62f9c9b59ea7b30d220ff6ba61047dab898c9a/SA-LUT/core/module/model.py#L383)、[context 分支 L87–208](https://github.com/Ry3nG/SA-LUT/blob/3e62f9c9b59ea7b30d220ff6ba61047dab898c9a/SA-LUT/core/module/model.py#L87)

冻结状态不能按常识填：`net.py` 的 freeze 循环被注释，而 trainer 的 generator optimizer 接收整体生成器参数；公开训练代码因此不能直接标成 frozen VGG。[net.py L62–83](https://github.com/Ry3nG/SA-LUT/blob/3e62f9c9b59ea7b30d220ff6ba61047dab898c9a/SA-LUT/core/module/net.py#L62)、[trainer.py L419](https://github.com/Ry3nG/SA-LUT/blob/3e62f9c9b59ea7b30d220ff6ba61047dab898c9a/SA-LUT/core/model/trainer.py#L419)

可吸收：共享统计描述与角色不对称交互可以并存。不要复制：直接把参考空间特征 cross-attention 到内容，就声称没有参考纹理泄漏；这一性质需要专门压力测试。

### 2.4 StatLUT：统计提取不等于语义解耦已经被证明

参考分支提取 Lab 的亮度直方图、ab 联合直方图和颜色条件平均亮度；不用预训练视觉骨干。mapper 将内容分布、参考减内容的统计差、全局统计汇成条件 memory；带颜色网格位置编码的 identity LUT 作为 decoder query。训练用随机 LUT 与同图空间变换，包含 LUT、图像和映射正则监督。它明确承认全局 LUT 缺乏语义局部能力。[原论文 §3、§5、附录 A](https://arxiv.org/html/2607.08227v1)

可吸收：统计差值是条件推断的直接证据，颜色网格位置不同于画面位置。不要复制：将“不带画面坐标”写成“完全不受内容影响”；海洋/草地占比本身改变直方图。其 H-Diffuser 是可选文本→统计分支，不能因此把参考图主流程归为图像 diffusion。当前未找到可核验的作者核心代码，细节以论文为准。

### 2.5 RefRetouch：强骨干要适配；参考前后对与单图参考不同

官方补充 §I 给出 SigLIPv2 `google/siglip2-so400m-patch14-384`：共享 Siamese 前后图分支，各得 1152 维，拼接投影成 2048 维 edit latent；基础参数冻结，attention 内 linear 加 rank-16 LoRA。pixel MLP 为 3→128→256→512→3，逐层加性 latent 条件，以 L1 重建训练。[官方 PDF 正文 §3.1、补充 §I，p15](https://tememuruts.github.io/RefRetouch-Project-Page/refretouch-paper.pdf)

注意主任务给的是“参考原图＋参考修图”，不能直接当作我们只有一张参考的设定。论文的 RAR 还有实现歧义：正文/项目页说用适配后的检索特征，补充 p15 Eq10 又说检索时禁用 LoRA；代码尚未公开，需向作者核实，不应擅自择一。[项目页](https://tememuruts.github.io/RefRetouch-Project-Page/)、[官方仓库](https://github.com/tememuruts/RefRetouch)

可吸收：用任务重建和受限颜色解码器共同塑造表征。不要复制：只引入大预训练 encoder，就将其输出命名为纯风格；也不能把两个 before/after embedding 直接迁移到我们无 before 的参考图而不解释。

### 2.6 PREEN：共享 CLIP＋明确低层统计，两阶段适配

共享 CLIP ViT-L/14 从输入/参考提取两个 768 维 embedding，另拼 123 维颜色统计；两个 residual MLP trunk 分别预测 tone/chroma，共 29 个编辑参数。先以 SA-LUT 输出反演伪参数，冻结 CLIP 训练回归；再对 CLIP 和 MLP 的 linear 加 rank-16 LoRA，以编辑结果的 Lab 损失适配。它直接覆盖“模型生成监督→小编辑空间”的大方向。[原论文 §3.3–3.4、补充 §8–9](https://arxiv.org/html/2610.36896v1)

可吸收：预训练 pooled feature 与低层颜色统计并用，冻结/适配状态分阶段核对。不要复制：只报 29 输出参数或 LoRA 参数量来暗示全模型轻；不要把参数回归前后两个阶段直接照搬，我们没有编辑器参数标签。其统计只是可迁移调色的证据，不是参考直方图硬匹配目标。当前未核实官方可执行模型源码。

### 2.7 NLUT：共享冻结 VGG，但网络生成成本与 LUT 应用成本不同

官方 `NLUTNet` 加载 normalized VGG；同一 encoder 在 256² 输入和参考上输出四尺度特征，经 AdaIN/splatting、池化拼接预测基 LUT 混合权重。`net.Net` 明确对四层 `requires_grad=False`，这比仅调用 eval 更有冻结证据。[nlut_models.py L68–146](https://github.com/semchan/NLUT/blob/66e271dd5740282d1b0f16d42ed5ca3f763ce818/nlut_models.py#L68)、[net.py L62–83](https://github.com/semchan/NLUT/blob/66e271dd5740282d1b0f16d42ed5ca3f763ce818/net.py#L62)

训练含 VGG 内容/风格特征约束、单调等映射约束，测试时还针对关键帧/参考做调优，再复用生成的全局 LUT。超快视频逐帧查询不代表任意新 pair 从零获得 LUT 同样快。[原论文 §3](https://arxiv.org/html/2303.09170v1)、[官方 train.py](https://github.com/semchan/NLUT/blob/66e271dd5740282d1b0f16d42ed5ca3f763ce818/train.py)

可吸收：统一表征空间和映射缓存。不要复制：把特征统计损失当作无偏摄影风格评分；我们目标是无测试时调优，比较时要计入它的初始化/调优时间。

## 3. 对我们下一版编码器的具体建议（研究判断，并非文献结论）

### 3.1 必须先固定一个可比较的基本接口

令共享单图编码器输出 `(全局颜色描述, 局部外观 token)`，两张图各编码一次，然后由角色特定的关系模块解释“输入当前状态→参考期望状态”。内容空间分支另行保留。共享骨干不要求共享输入/参考投影头，也不要求整个网络对交换输入对称。

共享的收益是假设两图用同一把尺子，不是数学上的内容解耦。分开的 head 则表达有方向的操作。如果取消共享，须与同参数预算的共享版本对照，避免只是参数更多。

### 3.2 最小的三类 encoder 对照

| 版本 | 目的 | 主要风险 |
|---|---|---|
| 固定 Lab/亮度条件颜色统计＋小关系网络 | 判断显式低层证据的下限 | 忽略区域用途；内容面积改变统计 |
| 小型共享 CNN＋显式统计旁路 | 判断局部外观能否补充颜色分布 | CNN 池化仍可编码物体/布局；不能命名即解耦 |
| 合法可用的预训练小视觉骨干，冻结与少量适配对照 | 检验初始化/任务适配是否比从零训练可靠 | 语义偏置、额外预训练成本；需要计入完整参数 |

三者复用相同全局渲染器，先关闭局部分支，统一数据、步数与训练分辨率。encoder 尚未比较清楚时，同时改变 LUT 形式和局部机制会失去归因。

低层旁路不应先做 InstanceNorm 抹掉每图均值方差，再期待从归一化特征恢复所有曝光/色温信息。可以保留 raw Lab/RGB 统计，规范化空间特征仅供形状/上下文。反过来，统计分支不等于完全语义免疫。

### 3.3 什么证据能决定是否改现有 prototype

1. 同输入、多参考：预测差异是否对应参考调色，而不是参考类别。
2. 同内容、受控色温/对比/色曲线变化：表征敏感度与渲染变化。
3. 参考 flip 与温和构图变化：检验不必要布局敏感度；不要用只保留天空的强裁剪宣称同风格不变。
4. 分布近似、内容不同的参考，与内容相近、调色不同的参考，交叉对照。
5. oracle 渲染误差与实际预测误差分开：先确定是读不懂参考，还是映射类无法表达目标。

不应只用 embedding t-SNE 好看、低 probe 分类准确率、或单一重建 loss 改善证明纯风格解耦。输出是否忽略参考、是否只减弱编辑，也必须排除。

## 4. 自审：哪些话目前不能写进贡献

- “首次共享编码器”“首次全局＋局部”“不用 diffusion 所以无幻觉”“统计自动消除语义”都不成立。
- “单图风格唯一可辨识”不成立；场景反射率、光源、相机处理和编辑存在歧义。
- “预训练 encoder 都不行”不成立；RefRetouch 的适配与 PREEN 的对照都要求我们实际检验。
- “我们从零的小网络参数少，所以同等信息更强”还没有证据；约 3,595 个独立训练场景与六万组合的差别必须说明。
- 若最终仅是小 CNN＋统计＋cross-attention＋LUT，没有具体失败机制和强控制实验，仍然是合理 baseline，不能因模块组合就预先保证 CVPR 创新。

可以争取的核心是：在明确失败条件下，证明某种任务表征与受限局部执行的耦合机制，能以相同编辑强度减少不可靠区域变化，并保持可泛化风格信息。该机制需通过上述 encoder 对照及渲染消融证实，而不是由本调研宣布已经成立。
