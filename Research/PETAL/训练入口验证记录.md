# 训练入口验证记录

时间：2026-10-29。本次仅在本地 Windows / PyTorch 2.12.0 CPU 运行临时合成数据的功能测试，没有访问 Trinity、没有进行真实数据训练，没有评估摄影调色质量。临时图片、checkpoint 和输出已由临时目录自动清理。

## 已通过的检查

- EXIF 转正后使用 RGB；portrait 输入先严格对齐生成目标的像素尺寸，再与目标共同等比例缩小；参考图独立等比例缩小。默认 batch size 为 1，不做裁剪、拉伸至正方形或 padding。
- 审核 JSON 仅影响样本选择；显式 reject 不参与训练/验证，不删除原文件；high-quality-only 只选择训练集显式优质样本，验证集不据此变成精选子集。未知 pair ID 和错误 collection 拒绝加载。
- split 直接使用冻结清单。输入图和参考图的路径、key 均参与跨 train/validation/test 泄漏检查；存在原 source_images.json 时，额外检查 duplicate_group、SHA 与源 split。diagnostic 不作为独立训练/验证集。
- 模型进行了两步真实前向、损失计算、反向和 AdamW 更新，并完成验证与 checkpoint 保存。
- 两步 checkpoint 恢复至第三步，与相同种子不间断三步训练的全部模型参数逐张量完全一致。检查了优化器、随机采样器与 Python/NumPy/PyTorch RNG 的恢复。
- global-only 一步训练关闭局部分支，但保留完整参数形状；随后 init-checkpoint 开启局部分支的新阶段成功，优化器与步数重新开始。
- 三步合成训练 checkpoint 的推理输出 PNG 保持源图 35×25 尺寸。它仅验证 prepare/render 接口，不代表真实调色质量。
- step=0 的 checkpoint 被推理入口拒绝。checkpoint 使用含 RNG 的 pickle，仅允许读取自己生成、可信的文件。
- manifest 路径越界和参考图跨 split 复用均被明确拒绝。

## 最终接口复测

在加入 style_aux 弱正则后的最终模型上，再次进行 CPU 合成测试，以下检查全部通过：

- 生产 manifest 中 `generation.max_image_edge` 驱动 Pillow `thumbnail`（含默认 reducing_gap=2.0），复现生成阶段的输入栅格；内容与未改色目标经共同缩小后的 Tensor 完全相同。目标尺寸与生成参数不符直接报错。无该字段的通用数据会明确警告，并采用 resize fallback，不声称精确复现生成过程。
- 冻结 source_manifest 中 key 对应的实际源路径核对通过；保留 key 但替换为另一图片路径被拒绝。source_manifest 缺失时明确警告只能检查 key/path 隔离。
- 可选 `--cache-dir` 存放低分辨率 lossless PNG，不修改原图。冷缓存与暖缓存三张图 Tensor 完全相同；暖缓存不再解码原图。修改参考源文件及 mtime 后缓存失效并重新生成。
- 含新增风格正则的两步恢复至第三步，与连续三步全部参数逐张量完全一致。
- 每次训练日志包含 mean_gamma、beta_l1_max、proxy_basis_correlation、preclamp_clip_fraction、gate_mean 和 active_local_branches；global-only 时 active 为 0。
- 原图 333×250 在 CPU 保持 uint8；只上传低分辨率条件与逐行块，最终 PNG 保持原尺寸。CPU 仍需要原图和输出的 O(HW) 存储。
- global-only checkpoint 到完整局部阶段 warmstart 再次通过。

Trinity 防误用检查已支持 `/ssd0`、`/ssd1`，启动时要求实际本地挂载与至少 100 GiB 空闲；`/tmp` 要求 150 GiB。这些门槛仅在 Trinity 主机生效，不能替代资源监控。

## 使用方式

先在计算节点本地目录暂存代码与 Dataset，训练工作目录、数据与 checkpoint 都放计算节点实际本地挂载的 `/tmp`、`/scratch` 或 `/ssd`。入口对 Trinity head hostname、共享路径和挂载类型进行防误用检查；实际仍需遵循 Trinity skill 的资源使用规则。

```bash
python Model/train.py --manifest Dataset/Photo_Triplets_v1/triplets.json \
  --output Experiments/tone_global --global-only --max-steps 10000

python Model/train.py --manifest Dataset/Photo_Triplets_v1/triplets.json \
  --output Experiments/tone_joint --init-checkpoint Experiments/tone_global/latest.pt \
  --max-steps 10000

python Model/train.py --manifest Dataset/Photo_Triplets_v1/triplets.json \
  --output Experiments/tone_selected --init-checkpoint Experiments/tone_joint/latest.pt \
  --review /local/path/triplet-review.json --high-quality-only \
  --learning-rate 0.00002 --max-steps 2000

python Model/infer.py --checkpoint Experiments/tone_selected/latest.pt \
  --content input.jpg --reference reference.jpg --output result.png
```

这里的步数仅是入口示例，不是已经验证的训练预算。默认模型 10,000 步、256 长边、每 500 步验证前 100 条用于开发监控；正式评测需冻结完整验证/测试方案，不能据测试结果调参。高质量子集需要人工审核实际存在对应标记，否则会报无可用样本。

中断恢复使用同一 output 和 `--resume .../latest.pt`；数据选择、损失或训练设置变化时使用新 output 和 `--init-checkpoint`。数据 fingerprint 绑定所选 ID 与路径映射，不代替图片字节完整性校验。

尚未验证：GPU 正式训练、真实 60,000 条数据全量加载、完整集群挂载环境、实际风格迁移效果、跨数据集泛化和吞吐。已有功能测试不支持任何新颖性或质量结论。
