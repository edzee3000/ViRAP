# 架构同行审查：从组件组合到可检验的研究假设

日期：2026-10-29。性质：实现前的自我质询，不是新颖性证明，也不是实验结果。仅核对原论文及作者项目/代码；未启动训练或访问集群。

## 审查结论

建议将首版收敛为：**无参考空间模板的紧凑条件预测器＋全局颜色映射＋最终 RGB 局部残差对有限颜色基的近似正交投影**。

核心待验证假设：在相同数据、编码器和渲染容量下，显式去除局部分支中可由指定颜色子空间解释的成分，能改善分支分工、训练稳定性及未见场景的质量，同时减少重复调色。不能预先写成“首次”“完全解耦”“零幻觉”或“满足 CVPR 要求”。

不把动态门控、低秩、直方图、无位置 token 和非扩散本身列为主要创新。先固定少量局部分支，防止多个机制一起变化，导致结果无法归因。

## 第一轮质询：已有方法是否已经覆盖？

| 原始想法 | 最接近的先例 | 本项目仍需证明的区别 |
|---|---|---|
| 无参考绝对位置的风格编码 | StatLUT 直接使用无空间统计，并做参考块重排实验 | 局部统计集合比纯统计保留了哪些有效信息，是否影响迁移质量 |
| 参考内容与摄影风格分离 | PETAL 的摄影嵌入、多视图及相反摄影编辑监督 | 轻量表征在相近成本下是否有可测优势，不能只用同类一致性损失 |
| 全局映射加局部上下文 | SA-LUT 的风格条件 4D LUT 与上下文图 | 去除参考空间路径是否改善干扰，同时保持局部表达 |
| 低分辨率预测、原分辨率颜色操作 | HDRNet 的双边空间局部仿射与 slicing | 这是成熟的效率设计，不是本项目首创 |
| 小模型、颜色映射、结构保持 | CLUT、LoR-LUT 及其他轻量映射 | 总成本与强轻量基线比较，不能只对比 12B |
| 现有模型生成监督，再训练和微调 | PREEN 已使用目标图反演伪预设并训练紧凑预测器 | 我们的局部渲染机制和对应证据，而非数据来源措辞 |

原始依据：

- [SA-LUT 原论文](https://arxiv.org/abs/2506.13465)、[作者代码](https://github.com/Ry3nG/SA-LUT)：参考多尺度特征控制 LUT，内容—参考交互产生空间上下文；因此“参考条件局部 LUT”不新。
- [StatLUT 原论文](https://arxiv.org/html/2607.08227v1)：无空间 Lab 统计、Transformer 预测 3D LUT，附参考块打乱分析；因此“去除参考空间位置”不新。其无空间性质也不等于从单张图恢复了唯一纯风格。
- [PETAL 作者项目](https://petal-pku.pages.dev/)：摄影表征由 Lab、直方图、多视图和摄影编辑学习，迁移器以参考与内容嵌入差控制 Lab+xy 神经映射。
- [HDRNet 作者项目](https://groups.csail.mit.edu/graphics/hdrnet/)、[官方代码](https://github.com/google/hdrnet)：低分辨率预测局部仿射系数，再用于原分辨率。
- [CLUT 原论文](https://cslinzhang.github.io/home/ACMMM2022/fengyi.pdf)、[官方代码](https://github.com/Xian-Bei/CLUT)：压缩 LUT 表征用于轻量增强。
- [LoR-LUT 原论文](https://arxiv.org/abs/2602.22607)：基 LUT 叠加低秩残差；低秩残差本身已有先例。
- [PREEN 原论文](https://arxiv.org/html/2610.36896v1)：风格迁移模型提供候选目标，经编辑器反演得到伪参数，再回归与微调；模型生成监督和两阶段学习不新。
- [LoopLUT 原论文摘要](https://arxiv.org/abs/2609.33593)：渐进区域细化也是需要比较的近邻。本次仅核对摘要，不将其具体训练细节视为已核实事实。

## 第二轮质询：到底“正交”于什么？

令输入颜色为 x，采用明确的 10 维颜色基：

`b(x) = [1, r, g, b, r², g², b², rg, rb, gb]`。

在代理分辨率的 N 个像素上，B 为 N×10。局部分支先产生最终三通道颜色修正 R_raw（N×3），再计算：

`β = solve(BᵀB/N + λI, BᵀR_raw/N)`

`R_perp = R_raw - Bβ`。

若 λ=0 且采用合法的精确最小二乘投影，可得到 BᵀR_perp≈0；λ>0 的 ridge 版本只有近似正交，应报告归一化正交误差，而非宣称严格为零。常量图、窄色域图可能使 Gram 矩阵退化，应采用稳定求解并测试有限梯度。

**只约束这 10 维经验颜色子空间，不约束任意全局颜色函数，也不等于对整个 3D LUT 空间正交。**基函数较弱时，全局与局部分支仍可重叠；基函数过强时可能去掉有用局部信号，或因样本不足变成对单图的记忆。应比较常数基、线性基、二次基及更丰富基的效果。

注意投影对象：若先把空间权重 m 投影，再计算 m(x,p)·ΔT(x)，颜色相关 ΔT 会破坏最终 RGB 修正的正交性质。因此默认投影最终 R_raw，投影之后不再乘空间相关掩码或颜色相关增益。图像级常数缩放不会破坏该线性性质。显示端 clamp 也会改变最终图像层面的关系，数学声明应定位在裁剪前的残差。

代理分辨率估计 β、原分辨率计算 R_raw(x,p)-b(x)β，保证的是代理像素空间的近似条件；全图颜色频率和局部权重上采样改变后，不能声称原分辨率同样正交。若需要精确全图性质，可分块累计全图 BᵀB 与 BᵀR，再第二遍渲染；首版可以先记录近似误差与额外成本。

## 第三轮质询：这是否只是重参数化？

是，有这个风险。若全局分支能表达 Bβ，则

`G + R = (G + Bβ) + (R - Bβ)`。

总表达族未必增加。研究价值可能来自参数分工、正则化和优化，而非“表达能力更强”。不能通过上述代数直接推出画质提升。

必要反证对照：

1. 相同全局与局部网络，直接相加，不投影。
2. 只对最终残差去均值。
3. 相同有限基，用软相关惩罚替代显式投影。
4. 全局分支预训练后再训练局部，排除仅仅来自训练顺序的收益。
5. 相同参数/计算预算的额外全局容量，排除局部分支仅仅提供更多参数。

如果显式投影不优于这些简单替代，不能把它硬写成核心贡献。可以保留为诊断工具，改从参考风格推断瓶颈寻找方法。

## 第四轮质询：无参考空间模板是否就不会幻觉？

不能保证。固定输入图时，参考条件仍可改变局部映射强度；由输入产生的空间图也可能利用边界、padding 或源图纹理形成错误结构。无位置集合只是对**固定 token 的排列**不变，不等于对真实裁剪、缩放和重新拼接不变；局部 token 本身还可能编码语义。

空间图低分辨率或平滑约束能限制细小结构，但仍可能产生大尺度光斑、阴影和光晕。残差颜色正交也不是反幻觉保证：完全均匀输入时，投影只能移除残差均值，零均值空间起伏依然存在。若声称严格平坦场保持，需要额外使均匀源图的局部路径为零，并测试 padding 和数值误差；否则只能把平坦场稳定性作为实验性质。

此外，非线性全局 LUT 虽无重采样，也可能产生色带、对比度损失或伪边缘。论文应使用“限制可生成的变化类型”，不使用“严格保持所有纹理”。

## 最小可行研究主线与验收门槛

建议首版固定：共享轻量风格编码器、无位置局部统计集合、输入独有空间 CNN、全局 3D LUT、2 个低分辨率局部颜色分支、最终 RGB 残差有限基投影。参考只预测颜色操作和样本级权重，不把参考空间图直接送进输出路径。门控先作为工程选项，不作为独立贡献。

先做三个验证：

| 假设 | 支持它的观察 | 否定后怎么办 |
|---|---|---|
| 数据确实需要局部自由度 | 留出像素/区域的 oracle 局部拟合优于全局拟合，且改善有视觉意义 | 收缩为全局映射，优先解决风格推断 |
| 分工约束产生独立收益 | 固定预算下，投影优于不投影、去均值和软约束，并改善外部评测 | 不再以投影为主要创新 |
| 参考空间路径有可测副作用 | 在相近风格强度下，去除此路径降低内容泄漏，同时保持有效局部变化 | 不声称参考空间限制带来稳定性优势 |

评测应同时包含 PETAL 合成目标误差与独立真实参考任务。前者主要检验拟合与泛化到生成器输出，不能单独证明真实审美更好。压力测试使用舞台灯、霓虹、文字及高频纹理参考；比较时控制风格迁移强度，避免“少调色”获得低伪影。人工精选也应有相同训练规模和步数对照。

当前可以承诺的产物是可运行研究原型、清楚的机制边界和可证伪实验。是否构成顶会贡献，取决于这些检验以及进一步的相关工作查重，而非模块数量。

## 第二轮实现审查

审查对象：`Model/tone_model/model.py`、`losses.py`、`data.py`、`train.py`、`infer.py` 的首版。该轮未在 Trinity 执行任何命令，未开始模型训练。

### 数据对齐：必须复现生成器输入的实际缩图算子

生成代码采用 Pillow `thumbnail((768,768), LANCZOS)`，其默认 `reducing_gap=2`；首版训练读取采用 `resize(target.size, LANCZOS)`，默认不进行同样的预缩减。因此即便最终宽高相同，也不是完全相同的像素。固定随机合成 3600×2400 高频图的本地验证中，768×512 两种结果的绝对差均值约 2.85/255、最大 17/255。这是缩放算子差异的验证，不是模型质量实验。

应先按每条生成记录复现生成器的 max_image_edge 和 EXIF/RGB 流程，再检查它与目标图尺寸一致，随后联合缩小输入与目标。遇到无法解释的尺寸差异应报错或明确记录，不能默默拉伸。为六万组训练提供确定性的低分辨率缓存，避免每一步重复解码巨幅原图。

### 代理颜色投影的外推风险与幅度界

代理缩图可能混合原图中相距很远的颜色，因此代理色域窄于原图色域。在代理图估计的多项式系数 β，可能在原图颜色上产生过大修正。SVD 截断能改善病态求解，但不自动限制原图外推的幅度。

采纳的改进是对**整个最终局部修正**施加图像级常数缩放：

`A = local_limit * sum_k(gate_k)`

`C = max_c sum_j(abs(β_jc))`

`gamma = min(1, local_output_limit / max(A+C, eps))`

`R_final(x,p) = gamma * (R_raw(x,p) - b(x)β)`。

数学条件：输入 RGB∈[0,1]；当前中心化线性/二次基中每个元素的绝对值不超过 1；空间权重经 tanh 限幅；局部 LUT 每个元素经 tanh 限幅，三线性查询是凸组合；gate∈[0,1]。于是每个通道 `|R_raw|≤A`、`|bβ|≤C`，得到所有有效输入颜色和空间位置上 `|R_final|≤local_output_limit`。零分母取 gamma=1。该界是保守界，可能显著减弱有效局部调整，需报告 gamma 的分布和对应质量影响。

gamma 对一个样本的所有像素、通道恒定，因此不会破坏该样本原有的代理残差正交关系。必须同时缩放 R_raw-Bβ，不能只缩放 β，也不能替换成逐像素 clip。原分辨率每个渲染块应共享同一个 gamma，训练 aux 中的实际 proxy_local 也应对应缩放后的残差。

该界仅约束局部 RGB 增量；不能推出总输出无裁剪、无色带、无伪边缘，或原分辨率严格正交。全局映射和最终 [0,1] 裁剪仍应单独诊断。

### 实验工程与复现边界

- 首版 renderer 行分块只限制查询临时量；若原图和输出仍全量保留 GPU，不能称显存与原图面积无关。108MP RGB float32 单张张量约 1.3GB，应使用 CPU 原图加分块上传/写回，并披露总输出存储开销。
- 冻结 source manifest 的 key/split/重复组检查，不等同于对实际文件做 SHA256 校验。应将 key 对应的路径与实际解析路径绑定；如未重新 hash，应如实记录只检查清单身份。
- 高质量筛选只影响训练集，但审核 reject 若同样作用于验证集，会改变验证成员。应在确定性 QA 后冻结验证集，并记录选中 ID 指纹；不得把变更后的验证集称作完全相同的对照。
- 提供全局、无投影、去均值、颜色投影的独立配置。若有全局 warmup，需要真实训练日程及 checkpoint 状态，而非只有模型开关。
- 至少记录 proxy 正交误差、局部增量能量、gate 均值、有效分支数、β 系数幅度、gamma 和输出裁剪率。训练 loss 下降本身不足以支持分工机制或低伪影声明。
- 首版只有行为单元检查和小合成优化，不能写成六万组训练已经完成，也不能宣称已测得实际风格效果或 4K 速度。
