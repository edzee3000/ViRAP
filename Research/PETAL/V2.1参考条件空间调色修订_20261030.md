# V2.1：参考条件化的空间调色

日期：2026-10-30。状态：架构、参数、形状与梯度验证；未完成完整模型训练或画质验证。

## 1. 修订原因

原空间权重 `M_k(p; I_c)` 对同一输入不随参考变化，只能改变局部颜色映射和门控。这是表达能力限制，不能作为保留内容的必要条件。

严格说，旧模型的输出变化不只有K个空间自由度，因为局部LUT还依赖像素颜色。但对输入中颜色相同的像素集合，在最终裁切前，局部残差每个通道只能在K张固定空间图的限制内组合。

修订为 `M_k(p; I_c,z_pair)`。空间特征只取输入图，pair条件由输入与参考共同生成；不复制参考纹理或参考坐标。

## 2. 实现

输入DINO最后层384→128通道、输入摄影CNN64通道、RGB/亮度/局部明暗差/梯度6通道，在64×64网格拼接成198通道F_c。

新增 `Linear(256,320)`，输出经过 `tanh × 0.25`，分成γ1/β1各96维、γ2/β2各64维。

```
F_c: [B,198,64,64]
  → Conv3×3 198→96 → GroupNorm(12)
  → (1+γ1)⊙F + β1 → SiLU
  → Conv3×3 96→64 → GroupNorm(8)
  → (1+γ2)⊙F + β2 → SiLU
  → Conv1×1 64→K → tanh
  → 输入平坦图保护系数
  → M: [B,K,64,64]
```

FiLM在归一化之后施加。特征缩放在[0.75,1.25]，偏置在[-0.25,0.25]；这些不是最终颜色变化界。FiLM初始权重std=0.001、bias=0，条件路径从初始化即存在；颜色输出头仍为零，所以初始整图输出仍是恒等映射。

M是有符号[-1,1]空间权重，不是语义概率，不要求和为1。完全恒定输入仍关闭局部路径，该保护不保证普通照片没有光晕。

输出简式：

\[
\hat I(p)=\operatorname{clip}\left[T_g(I_c(p);z)+s\sum_{k=1}^{K}g_k(z)M_k(p;I_c,z)\Delta T_k(I_c(p);z)\right].
\]

s沿用原局部幅度控制。默认投影关闭；若打开投影消融，还需减去颜色基底投影项，不能用简式替代所有配置下的完整等式。

## 4. 实验和验证

局部数量保留K=2作初始控制，支持K=4/8。后续对比固定/条件图 × K=2/4/8；可以补充保留FiLM但输入常量的容量对照。动态空间图不能消除单次映射低秩限制和64×64网格边缘分辨率限制。

不同时增加dense语义对应，先隔离条件化收益，再测试对应模块。仅全局pair向量调制不等于已建立跨图区域对应，也不保证人物肤色不变。

已检查：同内容换参考会改变空间图；空间图梯度到达FiLM和关系模块；none模式对条件不变且恢复原参数；K=2/4/8形状；图有界；恒定输入局部分支关闭；初始化输出恒等。测试仅证明依赖关系正确，不证明实际调色更好。

现有Trinity任务使用独立的全局LUT探针，没有空间模块。本次未改远端代码或正在运行的实验，避免破坏控制变量。

## 5. 与已有工作的边界

SA-LUT已通过内容—风格cross-attention产生context map，并结合4D LUT实现空间自适应调色。因此“参考条件化空间调整”不能包装为全新贡献。本修订采用全局pair条件FiLM和少量3D LUT残差，形式区别并不自动等于研究创新。需要证明专门学习的摄影表征与受约束算子的实际收益。
