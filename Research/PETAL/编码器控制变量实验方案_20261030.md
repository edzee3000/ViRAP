# 摄影调色编码器控制变量实验

## 问题与结论范围

利用已有的生成三元组，比较不同摄影表征对参考条件调色的帮助。第一轮是冻结预训练骨干的 representation probe，不等同于完整 V2 模型，也不能单凭结果判定解耦成功或人类审美更好。

不废弃现有 DINOv2 实现，不使用 PETAL 的权重、特征或中间激活。PETAL 仅是三元组的生成来源，数据来源仍需在论文中如实披露。

## 预先固定的实验组

|组|表征|主要问题|
|---|---|---|
|A|仅 Lab 亮度/色度直方图、分亮度区间统计和全局矩，无 CNN、无视觉骨干|低层统计能提供多少效果|
|B|公开预训练 DINOv2-S/14 + Lab CNN + 统计|当前骨干方案的标准化探针基线|
|C|公开预训练 DINOv3-S/16 + 相同光度分支|新一代骨干是否有实际增益|
|D|公开预训练 MAE-B/16 + 相同光度分支|重建式预训练家族的探索比较|
|E|DINOv3-S/16，无 Lab CNN、无显式统计|显式光度分支的作用|
|F|DINOv2-B/14 + 相同光度分支|补充与 MAE-B 接近规模的对照|

注意：D/F 仍有预训练数据集、patch 大小、优化配方等差异，不能声称只改变了预训练目标。C/E 同时改变新增参数和 token 数量，需报告容量；后续可增加“保留光度分支但输入常量”的容量匹配控制。A 也是信息量/容量下界，不是严格参数匹配实验。

## 统一的结构与输入协议

1. 两个角色各自从完整照片缩放至 224×224，不随机裁剪、不做改变色调的数据增强。内容图先遵循生成时的 Pillow thumbnail(768) 路径，保证与目标图对应。
2. 三种骨干均读取第 4/8/12 层。每层 patch 特征池化至 14×14，保留一个 CLS；DINOv3 额外 register/storage tokens 不送入读取器。三层共 591 个视觉 tokens。
3. 光度分支与 V2 同类：Lab CNN 的三个尺度各 64 tokens，加四组统计 tokens。编码维度统一256，16个查询，2层Decoder，8头，FFN1024。
4. 全局风格向量和 tokens 送入相同的有方向 Pair Conditioner。
5. 所有组使用**相同的全局条件 LUT 渲染器**：FiLM MLP 3→128→128→3，17³ LUT。关闭局部空间分支，避免输入图的另一条 DINO 通路混淆编码器对比。
6. 渲染与目标固定128×128完整照片方形缩放；属于低分辨率探针，必须在论文中标注。正式成图的原比例/原分辨率评测需要另做，不将探针指标冒充最终模型效果。
7. 骨干完全冻结并缓存特征；只训练光度分支、读取器、关系模块与颜色头。共同模块采用同种子相同初始权重。

## 数据、训练与模型选择

- 60,000条：59,100训练 / 400验证 / 400测试 / 100诊断。诊断集不用于训练或留出评测。
- 沿用原有源图、重复组隔离，`load_triplets` 校验两种角色，绝不按三元组重新随机拆分。
- 实际使用的去重源图在完整清单中共4,450张；60,000组不等于60,000个独立场景。训练集独立源图数量与重复引用应单独披露。
- 当前三元组尚未人工审核；原图审核不等于三元组审核。不使用“人工精选三元组”的表述。
- 正式每组3个随机种子：17、29、43；每次3个epoch，batch8，共22,164次更新，见实际配置。
- 每个epoch每条训练三元组恰好出现一次；相同种子在所有组使用完全相同的配对顺序。完成后自动核验顺序哈希。
- AdamW，初始学习率2e-4，weight decay0.01，cosine衰减至初始值的10%，梯度裁剪1。
- 损失：RGB L1 +0.05目标梯度差 +0.001 LUT平滑 +0.01越界惩罚。所有组相同。
- 每2000步及最后一步跑验证，按验证L1选择检查点；每次完整训练的检查点选定后，测试集只评一次。60步工程试验不评测试集。
- 固定3epoch是预算受控比较，不是所有方法均已收敛的保证。学习曲线仍在改善时，需要在不查看测试排名的前提下统一延长预算。

## 指标与诊断

主指标是对生成目标的平均RGB L1；次指标为逐图PSNR、Gaussian-window SSIM、平均像素ΔE76。均记录输入恒等输出基线。SSIM为11×11、sigma1.5、有效内部区域、RGB通道平均。

验证集额外将参考图循环错配：观察错误参考是否恶化结果。真实参考和打乱参考几乎没有差别时，不能只因L1较低就声称学会了参考条件迁移。

每组报告3种子均值及标准差，保存逐对结果。补充按内容图聚类的配对差值bootstrap作为敏感性分析，注明尚未充分处理共享参考图相关性，不能包装成无条件显著性结论。

需要后续补充的证据：盲评、完整分辨率与原比例成图、同内容不同影调区分、同影调跨内容一致性、裁剪稳定性，以及候选骨干的端到端适配。当前实验不能证明模型只提取了风格，也不能证明输出超越生成模型。

## Trinity执行与产物

- 节点：`trinity-2-23`；最多占用GPU0–7，不超过8卡；每张卡串行独立运行，不进行不必要的DDP。
- 本地根：`/tmp/shihangz/photo-tone-transfer/Experiments/encoder_probe_20261030/`。
- 已检查 `/tmp` 是节点本地tmpfs；`/scratch`仅55GiB空闲，不在其中追加数据。启动要求保留150GiB本地空间。
- 数据缓存、特征、日志、检查点写本地。结束后一次性归档到 `/data3/shihangz/photo-tone-transfer/Experiments/encoder_probe_20261030/`。
- 阶段：`prepare` → `pilot`（每组60步、验证64对）→ `train`（6组×3种子）。每阶段由独立tmux会话运行，失败留日志，不在head节点做实验。
- 代码：`Model/prepare_encoder_experiment.py`、`tone_model/encoder_probe.py`、`run_encoder_probe.py`、`encoder_experiment_jobs.py`、`summarize_encoder_probe.py`。
- 每次运行保存配置、权重来源哈希、训练顺序哈希、best/latest检查点、逐对评测、24组示例。结束自动生成 `summary.json`、`RESULTS.md`。
